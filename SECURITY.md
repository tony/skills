# Security policy

Report a vulnerability privately through GitHub: open the repository's
"Security" tab and choose "Report a vulnerability". Do not file it as a
public issue or pull request.

Include the plugin and skill, the steps that reproduce it, and what an
attacker gains. Reports about a skill that runs a command, writes files,
pushes, posts, or handles text from outside the repository (fetched pages,
pasted logs, review comments) are the most useful.

Fixes land on `main`; there are no maintained release branches.
