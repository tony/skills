# Aurora Fonts

A powerful, seamless, beautiful, modern font family for all your typography needs.
Aurora Fonts empowers you to create beautiful typography with a modern font family.

## Choose a format

| Format | Use |
| --- | --- |
| WOFF2 | Web pages |
| OTF | Desktop applications |

[View the specimen](docs/specimen.md) or [download a release](docs/downloads.md).

## Compatibility

The variable font requires an application with variable-font support. Use the
static OTF files when the application does not support variable fonts.
