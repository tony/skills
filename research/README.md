# README skill research

[Beautiful READMEs](beautiful-readmes/SKILL.md) is a standalone skill for
assessing, writing, and improving READMEs according to the reader's task. It
preserves useful examples, constraints, navigation, and project voice.

Its reference guides cover:

- [Assessment](beautiful-readmes/references/assessment.md): reader impact,
  evidence, preservation, and contextual exceptions.
- [Writing](beautiful-readmes/references/writing.md): examples, claims,
  structure, and conservative editing.
- [Patterns](beautiful-readmes/references/patterns.md): source-pinned examples
  and the conditions in which each pattern helps or hurts.
- [Niches](beautiful-readmes/references/niches.md): language and project-type
  considerations to apply only when relevant.

The [checksum manifest](beautiful-readmes.sha256) records the original bytes
from the research bundle. File modes are normalized for Git; the skill,
references, and evaluation inputs retain their original content.

[Evaluation cases](beautiful-readmes/evals/evals.json) cover writing, assessment,
preserving a working library README, and editing generated font documentation.
Some fixture READMEs deliberately contain incorrect commands or unsupported
claims for the assessment to identify.

This research snapshot is independent of the installable plugin catalog and
does not change the installed `readme-anti-slop` skill.
