# Tallylines project facts

Tallylines counts nonempty lines in one UTF-8 text file. Whitespace-only lines
do not count. It requires Python 3.11 or newer and has no third-party dependencies.
Users run the checked-out script directly. There is no published package.
The bundled sample produces 2. The program reads its input without modifying it.
This is a synthetic evaluation project; these facts are authoritative for the task.
