# Bridge

Print configuration for the client you use. Requires Python 3.11+ in this checkout.

## Claude Code

Choose this route for Claude Code:

```console
$ python3 bridge.py --client claude-code
```

## Codex

Choose this route for Codex:

```console
$ python3 bridge.py --client codex
```

These commands print JSON; they do not configure or launch your client.
Use one route, according to your client. See [configuration details](docs/config.md).
